How does this exchange work?

Pick a position on StrawPoll: SF (Strongly For), F (For), Abstain, A (Against), or SA (Strongly Against).

We combine SF+F as votes for and A+SA as votes against. Each ballot counts once. Following the WG21 subgroup guideline, consensus requires more than twice as many votes on one side as the other, excluding abstentions. At least four times as many votes gives this site's “strong consensus” label. Official chairs judge consensus after discussion.

Our graded prices are proportional to For2 : 2×For×Against : Against2. They total $$1.00. No consensus is the largest price between the two consensus thresholds. Exact threshold ties favor no consensus when rounding.

SF and SA get the full indicative payout; F and A get half. Abstain gets the full no-consensus payout. Empty polls have no price. The pricing formula, strong label and payout sizes are site conventions, and there is no real money at stake.

StrawPoll collects the votes and limits each poll to one vote per IP address. Shared networks share that limit; an IP address is not a person. Voting on StrawPoll requires JavaScript.

With JavaScript enabled, prices and vote counts refresh every minute. Without it, this page shows the latest published snapshot.

Solid lines and filled dots show saved snapshots. Dashed lines and hollow dots show the latest live data, marked “Current time”. That time is when this page fetched the vote totals; the browser does not save it to history. Expand the snapshot information to see each timestamp, price and five-way ballot count.

History is scheduled to refresh every five minutes through GitHub Actions; scheduled runs can lag. The live point still updates every minute. Older vote events cannot be reconstructed.
